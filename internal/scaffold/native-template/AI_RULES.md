Use React Native with Expo, NativeWind, and React Native Reusables. App.tsx is the entry screen and src/ contains screens and reusable components. Import Button, Card, and Text from @/components/ui. Use React Native primitives and NativeWind classes so the same source works on iOS, Android, and Web. Keep the Expo entry point, Metro configuration, and CSS import connected.

The source of Button, Card, and Text is the NativeWind registry of React Native Reusables (MIT). See LICENSE-react-native-reusables.
