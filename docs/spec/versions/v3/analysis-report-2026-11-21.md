## 4. 澄清问题记录

### 澄清 1 · v3 核心业务范畴聚焦【v3.REQ-001 ~ REQ-003】
- **问题**：v3 版本开发优先关注的核心技术重点。
- **用户答复**：聚焦「多应用管理与切换」、「可视化组件定位审查器」与「一键工程导出打包」。
- **处理动作**：固化至 `requirements.md` 并拆解为三大独立需求章节与 8 项原子 AC。

### 澄清 2 · 可视化组件审查器交互模式【v3.REQ-002】
- **问题**：审查器定位到 DOM 后的系统行为。
- **用户答复**：双向联动：点击 DOM 元素高亮源码路径，并将组件上下文自动填入聊天输入框，支持定向增量修改。
- **处理动作**：在 `design.md` 中设计时序图，规范 postMessage 消息结构与 `@src/components/...: ` 聊天框自动填充聚焦逻辑。

### 澄清 3 · 多应用工程管理与导出形式【v3.REQ-001 / REQ-003】
- **问题**：多应用展示布局与工程导出方式。
- **用户答复**：侧边栏/抽屉式多应用管理面板，导出支持完整工程 Zip 与打开操作系统文件管理器。
- **处理动作**：在 `design.md` 细化 `AppDrawer` 抽屉布局，在 `api.md` 增加 `ExportAppZip` 与 `OpenInFileManager` 方法。
